# Dawn Mentor

Demo site for QuantEdge by Dawnmentor.

## Live demo

After GitHub Pages is enabled, the site is at:

**https://neurobridgetech.github.io/dawnmentor/**

## Local development

```bash
cd draft
npm install
npm run dev
```

## Production build

```bash
cd draft
npm run build        # full build (includes Sites worker prep)
npm run build:pages  # static build for GitHub Pages
```
