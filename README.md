# Dawn Mentor

Demo site for QuantEdge by Dawnmentor.

## Live demo URL

**https://neurobridgetech.github.io/dawnmentor/**

## Turn the demo on (one-time, ~30 seconds)

1. Open this link while logged into GitHub:  
   **https://github.com/neurobridgetech/dawnmentor/settings/pages**
2. Under **Build and deployment**:
   - **Source**: choose **Deploy from a branch**
   - **Branch**: choose **gh-pages**
   - Folder: leave as **/ (root)**
3. Click **Save**
4. Wait 1–2 minutes, then open:  
   **https://neurobridgetech.github.io/dawnmentor/**

That’s it. You do **not** need GitHub Actions for this demo.

## Local development

```bash
cd draft
npm install
npm run dev
```
